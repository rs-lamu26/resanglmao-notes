# AI概念学习Skill仓库

## 仓库用途
本仓库存放项目级Skill：概念学习资料生成Skill，用来输入AI概念自动生成结构化自学笔记。

## Skill存放路径
`.workbuddy/skills/concept-learn-skill/SKILL.md`

## WorkBuddy调用方法
1. 使用WorkBuddy打开本仓库根目录
2. 在Skill下拉列表选择 concept-learn-skill
3. 输入想要学习的概念名词，执行运行，即可输出学习资料。

## 已生成学习资料
- learning-materials/agent.md Agent概念学习资料
- learning-materials/llm-context.md 大模型的上下文学习资料
- learning-materials/skill.md Skill概念学习资料
- learning-materials/concept-relationship.md 三个概念之间关系说明
