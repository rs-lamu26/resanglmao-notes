# 概念学习资料生成Skill

## 适用场景
当需要快速学习一个陌生AI概念，生成一份可供个人查阅、复盘的结构化学习笔记。本Skill支持任意新概念输入，不局限于Agent、大模型上下文、Skill。

## 输入信息
输入：一个AI领域概念名词（文本字符串）

## 生成步骤
1. 接收用户输入的概念名词
2. 搜集该概念的核心定义，撰写个人理解解释
3. 梳理概念的核心机制、内部组成
4. 列举1个真实可落地的应用场景
5. 梳理容易混淆的相近概念、使用边界与局限性
6. 附上可访问的公开参考资料来源链接
7. 整理输出结构化markdown文档

## 输出结构
输出文档必须包含下面全部板块：
1. 概念个人解释：自己理解的通俗表述，禁止大段复制AI原文
2. 核心机制与组成：概念如何工作，关键构成部分
3. 实际应用场景：举1个现实使用案例
4. 易混淆问题 & 使用边界：什么情况该用、什么场景不适用，和相似概念区分
5. 参考资料来源：真实可打开网页链接，禁止编造

## 资料来源要求
优先官方文档、公开技术博客，链接必须可访问，不允许虚构来源。

## 自检要求
输出完成后自检：
1. 是否全部板块齐全
2. 概念解释不存在事实错误
3. 参考链接有效
4. 没有写死固定概念，能够适配其他新的输入概念
