# 大模型的上下文（Context）学习资料

## 一、概念个人解释

我自己是这么理解的：**上下文就是模型这一次回答问题的时候，眼睛能看到的全部文字。**

打个比方：模型像一个记性只有"当前屏幕"的工作人员。你把什么贴在他屏幕上，他就只能根据屏幕上的东西回答。
屏幕塞满了，最早贴上去的纸就被挤掉了（或者被压缩成一张摘要），他就真的"忘了"。

几个关键点：

- 上下文 ≠ 模型学过的知识。训练数据是它脑子里长期的东西，上下文是这次临时摆在他面前的。
- 上下文是**一次性**的。对话关掉，上下文就没了，下次开新对话他什么都不记得（除非做了记忆机制）。
- 上下文是按 token 算的，不是按字算。中文一个字大概一到两个 token。

官方的说法是：上下文窗口代表模型的"工作记忆"（working memory）。我觉得这个比喻最准。

## 二、核心机制与组成

**1. 什么是上下文窗口（Context Window）**

模型一次请求里能塞进去的 token 总上限。不同模型不一样，比如 Claude 系列有 200K，部分新模型到 1M token（官方文档里写的上限值，具体看模型）。

**2. 哪些东西全部算进上下文**

这一点最容易踩坑，不是只有你说的话：

- 系统提示词（system prompt）
- 每一轮的用户消息 + 模型的回答
- 工具的定义，以及工具返回的结果
- 上传的文件、图片、文档
- 模型的思考过程（开启扩展思考时）

也就是说，Agent 跑十步，工具返回的结果全都堆在上下文里，非常容易爆。

**3. 上下文是怎么涨的**

每一轮都是"之前全部内容 + 这一轮的新内容"，完整保留。所以是**线性累积**，跑着跑着就满了。

**4. 满了怎么办（上下文管理）**

Anthropic 官方给了四种常见做法：

- **即时加载（Just-in-time）**：别一上来全塞进去，需要什么再让工具去取。这是设计习惯，不是 API 功能。
- **服务端压缩（Compaction）**：对话太长时，把前面的内容自动总结成一小段，腾出空间。
- **提示缓存（Prompt caching）**：把系统提示、工具定义这些不变的部分缓存起来，省钱省时间。
- **记忆工具（Memory tool）**：需要跨对话长期保存的东西（用户偏好、上次结论），写到外部存储里，下次再读。

**5. 长上下文不等于更好**

官方明确提了 "context rot"（上下文腐化）：token 越多，模型的准确率和召回率反而下降。
所以**筛选放什么进上下文，和上下文有多大一样重要**。塞一堆无关内容进去，不只是浪费钱，还会让模型变笨。

## 三、实际应用场景

**场景：用大模型复习一整个学期的课程资料。**

假设我把 20 份课件、作业要求、老师给的教程全部一次性粘进对话框，让它帮我划重点。
结果通常是：要么直接超窗口发不出去，要么勉强塞进去了，但它只认真看了开头和结尾，中间的内容回答得乱七八糟——这就是 context rot。

正确做法（对应上面四种管理手段）：

1. 别全塞，把资料放文件夹里，让模型**需要哪份读哪份**（即时加载）；
2. 聊了很久之后，把前面已经确认过的结论**压缩成一段摘要**再继续（压缩）；
3. 固定的要求（输出格式、评分标准）放系统提示里**缓存**复用（提示缓存）；
4. 这次总结出来的重点，写成一个 md 文件存下来，下次开新对话直接读文件（外部记忆）。

实操下来，一个几十轮的对话能一直跑下去，靠的就是这四件事。

## 四、易混淆问题 & 使用边界

**1. 上下文 ≠ 记忆**

上下文是这次对话临时能看到的东西，关掉就没。记忆是跨对话保存的，得靠外部文件或数据库实现，模型自己不会记。

**2. 上下文 ≠ 训练数据 / 知识库**

上下文是临时塞进去的，训练数据是模型训练时学的。想让模型知道新东西，要么塞进上下文（RAG 就是这么干的），要么微调模型。

**3. 长上下文 ≠ RAG 的替代品**

长上下文适合"一次要看全部内容才能判断"的任务（比如通读一份合同找矛盾）；
RAG 适合"资料海量、每次只用一小部分"的任务（比如几万份文档里问答）。
不是二选一，实际常常一起用。

**4. 什么时候要警惕**

- 跑 Agent 跑了很多步之后，前面早期的目标容易被"挤出去"，模型会跑偏——这时候该压缩或重开。
- 回答突然变差、开始重复、答非所问，先怀疑是不是上下文太长 / 塞了垃圾内容，而不是先怀疑模型不行。
- 输出也有上限（一个请求能生成的最大 token 数有限），上下文大不代表能一次输出很长。

**5. 一个常见误会**

"我把文件传上去了，它应该记得吧？"——只要这个对话还在，就在上下文里；新开一个对话，它完全不知道你传过什么。
